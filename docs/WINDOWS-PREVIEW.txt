Plico — Windows 开发预览版

使用方法
1. 解压整个目录，双击 Plico.exe。
2. 用 Open… 选择本地 Git 仓库，或从 PowerShell 启动：
   .\Plico.exe "C:\code\my-repository"
3. Log 查看提交历史；选提交后双击文件或在文件列表按 Enter 打开 Diff Tab。
   默认独立 Tab 显示完整文本上下文；Settings 可切换到底部预览。
   左侧图标栏一次打开一个工具窗口：本地更改（Commit 提交）、
   Project（项目文件，可编辑）或已保存的更改（stash）。点击当前图标可收起。
   本地更改查看暂存、未暂存、未跟踪文件和冲突状态。

运行环境
Windows x64，需要安装 Git for Windows 并让 git.exe 可从 PATH 找到。
字体和图标已内嵌，不需要另外安装。该包不包含 Git。

快捷键
Ctrl+O：打开仓库；Ctrl+F5：刷新
Ctrl+F：聚焦 Text or hash 查询；Ctrl+Shift+C：复制提交 ID
Ctrl+D：打开 Diff Tab；Esc：关闭活动 Diff Tab
普通文件正文中 Esc 清除选择并保留Tab；Ctrl+F4关闭当前文件Tab。
F4：从当前 Diff／历史预览跳转到工作区源码；可先点击正文定位行，
工具栏铅笔按钮同样跳转。首次打开源码会等文件加载后应用行定位。
F7 / Shift+F7：下一个／上一个差异

设置与语言
右上齿轮打开设置弹窗；支持跟随系统（默认）、中文和 English。
Windows 中文界面语言使用简体中文，其余回退英文。
Apply／应用保存而不关闭，OK／确定保存并关闭；取消丢弃尚未应用的修改。
可选择独立 Diff Tab 或底部预览，偏好保存在 %LOCALAPPDATA%\GitReview。

审阅与基础 Git 操作
浏览操作只读；普通刷新不联网。顶栏左上主菜单 → Git 提供
Fetch／获取、Pull／拉取、Push／推送和 Update Project／更新项目。
更新项目与推送也可通过顶栏图标进入。
Fetch 主动获取并清理远端跟踪引用。Pull 可选择远端、分支及选项；
Update Project 按当前跟踪分支执行更新。拉取／更新可能合并或变基并产生冲突。
Push 先展示源、远端目标及待推送提交，按确认的操作执行。
顶栏分支菜单提供检出动作与 Checkout Tag or Revision；Log 提交右键菜单
也可检出指定版本，检出提交可能进入 detached HEAD。
Log 内分支树的选择只过滤历史，远端分支是本地保存的 refs。
变基未结束时提供 Continue Rebase／继续变基和 Abort Rebase／终止变基。
请先用外部 Git 工具解决并暂存冲突；继续时可能打开提交消息编辑器。
终止需要确认；取消正在执行的操作不等于撤销已经发生的 Git 写入。
本地更改的 Commit 面板：选择文件用于预览，勾选用于纳入提交；
输入消息后 Commit／提交，或 Commit and Push／提交并推送。
Amend last commit 可修改最后一次提交，也支持仅修改消息。
当前按文件选择，不提供任意差异块暂存编辑；提交成功后才进入推送流程。
Log 支持 Ctrl／Shift 多选；右键 Squash Commits 压缩选中提交并编辑消息。
需满足当前历史与保护分支等检查，成功后可通过 Undo Squash 尝试撤销，
撤销前仍会复验仓库状态。冲突使用外部工具解决后继续／中止；
在外部处理好 Squash 保存的更改后，可在已保存更改中选择“已在外部处理…”。
确认只清除应用恢复记录，保留 stash 和文件；记录已变化或仍有冲突时拒绝清理。
非普通文件或超限恢复记录仍需外部检查。
两选 Log 提交后右键 Compare Versions，直接比较两个提交的文件树，
不是 merge-base 比较。左侧更改面板默认选首个文件；Enter／双击／显示差异
打开复用的完整 Diff Tab。预览打开后，树选择与 Diff 文件导航双向联动。
Esc 关闭该预览并返回文件树；关闭比较面板也会释放它所属的预览。
已保存的更改提供 Apply／应用和 Pop／弹出，明确触发后才恢复修改。
本版不提供通用文件编辑、任意差异块暂存编辑或完整冲突解决编辑器。
认证提示仅用于当前操作，不提供密码保险库。
请保留同目录 plico-askpass.exe 和 plico-editor.exe。
Merge 默认与第一父提交比较；图形分叉本身不表示冲突。
每个历史窗口最多 10,000 条，可通过 Older/Newer window 继续查看。
只按需读取活动文件的 Diff；超大文件和不支持的内容会显示说明。
设置 → 编辑器标签页 → 启用预览标签页，默认关闭。
开启后选择Project文件复用一个斜体预览Tab，焦点保留在文件树；
Enter、文件双击或Tab双击将预览转为普通Tab，之后不被新预览替换。
关闭开关保留当前文件并将预览转普通；开关跨重启保持。
切换工具窗口、文件Tab或收起Project会取消尚未打开的延迟预览。
普通文件切换/重载保留活动文本选择及方向，非活动正文仍释放。
文件和Diff共用Tab顺序，新Tab插在当前Tab后，标题关闭回左邻。
视口恢复的滚动体验及不同缩放仍待手测。
Project 目录每页最多256项，末尾“加载更多文件”可单击或按Enter/Right。
Home/End定位已加载树的首末项；折叠释放子树。
刷新保留已展开目录、加载范围和仍存在的选择；已删除目标退回可见父目录。
目录暂时不可用后重试可恢复原上下文，后续主动选择/展开优先。
整棵树最多保留16384项；达到预算后可折叠其他目录再继续。
分页期间目录变化会提示刷新，不混合显示不同目录版本。
Project按Rebased默认名称规则隐藏.git、缓存目录、编译缓存和备份文件。
.env、.gitignore等普通点文件以及Git忽略的普通文件仍可浏览。
Diff和Project文件读取失败显示短摘要，可重新加载和复制错误详情；
Project目录失败可刷新重试。其他操作错误在右下状态栏提示。
重新加载Diff只读取数据，不会重复提交、推送等写操作。

本轮 UI/UX 更新

窄窗时筛选项收进右箭头入口，放宽窗口后恢复并保留条件；User／Paths编辑器可以在溢出菜单内打开。
项目字母图标独立使用JetBrains Mono半粗体，顶部、项目菜单和欢迎页共享居中与留白。
Branch/User/Date/Paths选中后显示×，只清除对应筛选；双击Branches中的HEAD筛选其可达历史。

文件和选中范围的 Git 历史
在 Project 打开的只读文件正文右键：
- 显示历史：打开文件历史 Tab，选择版本查看与文件历史图中父版本的差异，使用对应历史路径；支持重命名追踪。
- 显示选中范围的历史：打开独立窗口，默认仅显示改变所选行块的版本；没有选区时使用光标行。
  可切换到全部版本，查看工作区未提交变化和完整提交说明。
Diff／历史预览工具栏的铅笔按钮或 F4 跳转到当前工作区源码；按旧版本行号映射当前位置，文件保持只读。
从历史跳到源码再切回历史 Tab，会恢复选中的版本。
历史首批100条，可加载更多，最多1000条；超出会提示。单版本5MiB、选区块缓存16MiB、比较合计200000行及约1秒预算。
这些浏览功能不会执行 fetch、checkout、commit 或修改工作区。

文件历史 Tab 提供 graph 和独立分支筛选，默认 HEAD；点击 × 查看所有分支，可在下拉中选择本地／远程分支或标签。
切回历史 Tab 会恢复分支条件和选中的版本。历史默认100条，可继续加载到1000条；复杂仓库超过有界祖先／引用预算时显示加载失败，详情可复制。
历史打开后可直接用上下方向键选择版本；Ctrl+F4 关闭当前源码／历史／Diff Tab，并返回邻近 Tab。设置等模态弹窗打开时，该快捷键不关闭背后的 Tab。

文件历史多选比较：Ctrl+单击切换版本，Shift+单击或Shift+上下方向键扩展范围。Diff使用最上方／最下方所选版本作端点，支持跨重命名；切回Tab或刷新按commit ID保留选择。详情最多展示前50条，多选时可查看各条完整说明、作者／提交者与时间、分支／Tag和包含分支，溢出有滚动条。列表与详情、上方区域与Diff可分别调整高度；切选择会取消旧详情查询。

读取错误
历史、版本比较、已保存更改的读取失败提供短说明、刷新和详情。Project 的 IO 诊断也可打开详情。
详情弹窗可复制完整原始输出；使用关闭按钮、X、Esc 或 Enter 返回。所有权错误不会自动修改 Git 信任配置。

合并历史说明：恰好两个有效父版本时以三栏显示“父版本／合并结果／父版本”。
三栏按共同未变化行对齐，空白补齐不参与复制；每列可Ctrl+A／复制，F4或铅笔
跳转当前工作区对应行，F7／Shift+F7浏览变更。多选或缺少一侧继续按请求规则用两栏。
三栏每来源最多5MiB，最多100000对齐行；行级颜色上增加词内变更强调；超大块保留行级颜色，连接曲线仍待还原。

提交失败显示简短摘要，可查看／复制有界诊断并关闭提示。草稿与勾选保留，修复原因后
请再次点击提交／修订提交，不会自动略过hook或推送。中英文摘要可随语言设置切换，
Git原始输出不翻译。超长输出受进程尾缓冲与详情展示预算约束。

文件历史顶部的显示选项（眼睛图标）可勾选“显示详情”，默认关闭，按项目记忆。
显示或隐藏详情保留所选版本和Diff；列表与Diff的分隔比例仍可拖动调整。
隐藏期间不持续持有详情卡片及其加载任务，偏好保存在应用配置目录，不写入仓库。

主工具栏的项目名称／图标可下拉打开仓库或选择最近项目，按已打开／最近分组。
分支菜单包含“提交…”：打开已有提交侧栏并聚焦说明，保留草稿；支持菜单搜索
和键盘选择，入口不会直接提交。正常分支、标签与其他游离状态显示不同图标。

Windows 界面文字默认采用系统消息框字体，与 Rebased 默认字体来源一致；
界面绘制与详情省略宽度测量使用同一字体。系统字体更改后请重启应用。
代码／Diff正文继续采用内嵌 JetBrains Mono，不提供编辑功能。

本版Git Log改为按行预留graph宽度，作者／日期独立显示。长连线默认按Rebased的30行阈值显示端点箭头并省略中间显示区段；底层父关系完整。端点箭头行仍可较宽，Commit单元格内裁剪不会挤走作者／日期。Log顶部眼睛菜单可切换“长连线”，按项目记忆，切换只重绘当前数据、保留选择与Diff；箭头点击跳转尚未接入。

Log长边箭头：悬停查看目标提交，点击向上／向下箭头选择该边对应的可见提交并定位；不会清除筛选。目标不在已加载窗口中时只显示说明并保留原选择，不自动扩大加载范围。

Plico 更新：提交列表与文件历史显示本地时间、今天／昨天或最近时间；已打开项目时选择另一个项目，可选当前窗口或新窗口。左上角使用新的 Plico logo，与工具窗口按钮共用中心线。旧 GitReview 设置路径保留用于兼容。便携包的应用入口为 Plico.exe；plico-askpass.exe／plico-editor.exe 仍须放在同目录。

多窗口语言修正：在任一窗口切换中英文后，其他已打开窗口的搜索提示、已有提交说明输入框会同步，保留输入内容。关闭最后一个窗口会正常退出程序。

可选启动诊断（开发验证）
.\Plico.exe "C:\code\my-repository" --history-limit 1000 --startup-report "C:\temp\plico-startup.json"
输出目录必须存在，输出文件必须不存在；每次进程仅记录首个窗口一次。
报告记录首批已发布的提交／图行数及 prepaint 时间，不表示 GPU 呈现或可交互时间。
不传 --startup-report 时不写报告；报告不包含仓库路径、提交内容或 OID。
原生可交互验证脚本 scripts/windows-startup-data.ps1 另行核对可见节点与完整 OID。

推送与强制推送
推送弹窗按“本地分支→远端目标／待推送提交”和右侧变更文件树组织；目录可展开／折叠，Ctrl+D查看选中文件差异，铅笔跳转只读源码。
底部“推送标签”默认不勾选；All推送全部标签，Current Branch只随提交推送可达的附注标签。
Push主按钮为普通推送，下拉菜单提供强制推送。强推先显示目标及风险确认，取消返回预览；“不再提醒此目标”仅确认后按项目／远端／分支记忆。
强推使用显式force-with-lease，远端出现未见的新提交时拒绝，不自动Fetch／Pull后重试；默认main/master禁止强推。本版未提供自定义保护策略、plain force或跳过hook设置。
推送准备读取失败会保留诊断入口，可查看／复制详情；与未检出本地分支的提示分别处理。

基础编辑
工作区源码和Commit Diff的工作区内容可编辑，空闲或失焦自动保存，Ctrl+S立即保存。
历史、暂存区及Stash快照保持只读；自动保存不会自动暂存或提交。
保存冲突时保留草稿并阻止关闭，请先处理磁盘外部修改。

已知限制
这是首个Preview版本；单栏编辑Diff使用显示行号，差异背景尚非完整整行。
程序尚未进行代码签名；不包含自动更新或Git本身。
