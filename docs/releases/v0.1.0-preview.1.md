Plico 首个公开预览版：Windows 优先、低内存、以 Git 审阅为主的桌面客户端。

### 使用
下载 `Plico-0.1.0-preview.1-windows-x64.zip`，解压整个目录后运行 `Plico.exe`。
需要 Windows x64 和 PATH 中可用的 Git for Windows。旁边的 `.sha256` 文件用于校验下载完整性。

### 功能
- Git Log / Graph、过滤、提交详情、单栏与双栏 Diff。
- 文件浏览、代码高亮、文件及选区历史、跳转源码。
- Commit / Amend、Fetch / Pull / Push、Checkout、Stash 与 Squash。
- 工作区基础编辑、自动保存及共享撤销历史；历史和暂存快照保持只读。
- 中文与英文界面，默认跟随系统语言。

### 已知限制
这是 Preview，不是稳定版。单栏编辑 Diff 行号与整行底色、部分 UI 细节仍待完善。
不包含代码补全或完整 IDE 功能。尚未代码签名，没有自动更新；Git 需单独安装。
首版以实际使用反馈为后续修复依据，不宣称所有输入法、DPI 和长会话场景均已验收。
