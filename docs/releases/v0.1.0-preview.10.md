Plico 第十个公开预览版，完善日常 Git 操作与历史审阅流程。

### 新增功能

- 支持从文件历史获取指定版本，保留 HEAD 和暂存区；大文件恢复使用流式处理。
- 支持从 Log 发起 Cherry-pick，以及冲突后的继续、中止和空提交处理。
- 新增 Reflog 浏览与从选中提交创建恢复分支。
- 支持创建轻量／附注标签及单独推送标签。
- 支持初始化仓库，并完成首次提交、定义远端和首次推送。
- 支持打开子模块仓库，以及在父仓库提交子模块指针。
- 新增 Markdown 原生预览及编辑／预览布局切换。

### 使用体验与修复

- Log 按过滤条件显示已加载数量和总数，异步计数不阻塞首屏；文件历史在后台继续加载。
- 修正文件历史预览失败污染列表状态和总数的问题。
- 改进跨仓库 HTTP 凭据复用、账号授权生命周期，以及提交、回滚和冲突处理的状态保护。
- 修正差异导航和编辑器生命周期问题，并对齐常见无效正则的处理行为。
- 美化并本地化 OAuth 回调结果页，调整欢迎页按钮间距。

### 下载与升级

下载 `Plico-0.1.0-preview.10-windows-x64.zip`，退出旧版，完整解压到新目录并运行 `Plico.exe`。
保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要混用旧包文件。原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows；同名 `.sha256` 文件用于校验。

### 验证与已知限制

新增流程已通过核心与桌面回归，并使用独立仓库和本地 bare remote 进行 Windows 原生验收。
发布流水线再次执行核心检查、桌面回归、Windows 专项测试与构建。

仍为 Preview，未代码签名，没有自动更新。差异预览保留 5 MiB 限制，但历史文件恢复不再受此限制。
Cherry-pick 暂不提供合并提交的 mainline 选择；Reflog 最多显示 10000 条且不能找回已被清理的对象。
子模块支持打开及提交父指针，未提供初始化和递归更新管理。界面未宣称逐像素完全对齐 Rebased。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
