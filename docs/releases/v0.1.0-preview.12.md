Plico 预览版 v0.1.0-preview.12，完善多仓库协作、工作树与历史整理流程。

### 新增与改进

- 项目支持聚合多个 Git 仓库及已初始化的子模块；Log、过滤、导航及操作按所属仓库处理。
- Log 新增仓库颜色列：相邻同仓库提交连成色条，点击展开／收起仓库名称，悬停显示完整路径，按项目记忆展开状态。
- 新增 Git 工作树面板，支持创建、打开与移除工作树，以及键盘选择和右键操作。
- 支持分支比较、分支重命名，以及将当前分支 Rebase 到选中的本地或远端分支。
- 新增交互式 Rebase 计划编辑，改进 Git 编辑器请求、冲突后的继续／中止及多仓库操作的恢复流程。
- 改进项目更新、子模块相关流程和浅克隆仓库的完整历史获取；分离 fork 工作流中的拉取跟踪与推送目标。
- 收拢 Log 页面身份、Git 交互会话、多仓库恢复流程及分支弹窗的生命周期，避免过期异步结果影响当前界面。

### 下载与升级

下载 `Plico-0.1.0-preview.12-windows-x64.zip`，退出旧版，完整解压到新目录并运行 `Plico.exe`。
保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要混用旧包文件；原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows，同名 `.sha256` 文件用于校验。

### 验证与已知限制

相关功能已使用独立仓库和本地 bare remote 验证，并完成核心、桌面状态及 Windows 原生界面检查。
发布流水线再次执行核心检查、桌面回归、Windows 专项测试与构建。
长交互式 Rebase 计划的拖动边缘滚动，以及 Log 仓库名在滚动中的显示效果，仍待用户手测。

仍为 Preview，未代码签名，没有自动更新；尚未宣称完整像素级对齐 Rebased。
子模块不提供独立 init/sync 页面操作。差异预览保留 5 MiB 限制。
源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
