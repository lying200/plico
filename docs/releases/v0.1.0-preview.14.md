Plico 预览版 v0.1.0-preview.14，包含 Islands Light、文本校对及 Fetch / Push 预览性能优化。此前 preview.13 未创建发布 tag，本包一并包含其改动。

### 新增与改进

- 设置 → 外观 → 主题支持 Islands Dark / Islands Light，即时切换并保存，重启和新窗口沿用选择。
- 浅色配色覆盖主窗口、控件、文件图标、语法、Diff 和三方合并高亮；切换保留字体、编辑内容及选区。
- 校对提交、历史整理、推送及冲突恢复等界面的中英文术语与提示。
- 无变化的成功 Fetch 保留已有历史，避免无必要的完整重载；失败、取消、浅克隆加深等情况仍刷新。
- Push 预览批量读取提交变化，保留重命名、合并提交、浅克隆边界与取消检查。
- 操作刷新同步引用观察基线，避免后续轮询再次重载整轮历史。
- 测试入口隔离用户配置、临时目录和 Git 环境，增加完整 Windows CI 回归。
- 修复 Windows 调试启动的栈空间问题，以及日志预览刷新和弹出层边界问题。

### 性能与验证

Windows 原生、小仓库和本地 bare remote 的同场景对照中，空 Fetch 查询链约从 2.04 秒降至
0.95 秒，单提交更新从 7.57 秒降至 5.88 秒，20 提交 Push 预览从 2.93 秒降至 1.83 秒。
推送确认的首轮查询未加速，但消除了之后的重复整轮历史刷新。这是 Git 命令时间线，
不是精确 UI 延迟，也不代表公网传输性能。

开发版本本地最终核心 952 项、桌面 188 项、导航 10 项全部通过；发布流水线另行验证最终
版本并构建 Windows 包。早先两项编辑器等待超时及复测记录保留在性能报告中，未放宽测试时限。

### 下载与升级

下载 `Plico-0.1.0-preview.14-windows-x64.zip`，退出旧版，完整解压到新目录并运行 `Plico.exe`。
保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要混用旧包文件；原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows，同名 `.sha256` 文件用于校验。

### 已知限制

尚未完成全部界面的逐像素还原；三方合并保留既有整行高亮，编辑中的未解决计数仍有显示差异。
仍为 Preview，未代码签名，没有自动更新。子模块不提供独立 init/sync 页面操作；差异预览保留 5 MiB 限制。
源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
