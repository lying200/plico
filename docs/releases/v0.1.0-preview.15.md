Plico 预览版 v0.1.0-preview.15，改善刷新时的浏览体验，并优化 Git 查询与历史加载。

### 新增与修复

- Changes 刷新期间保留已有列表的差异查看能力。
- 提交文件列表新增右键操作，包括与本地比较、获取指定版本等。
- 修复多仓库历史中各仓库 HEAD 节点与包含关系的显示。
- 修复仓库管理目录变化后的监听绑定，保留配置、浅克隆和历史解释变化的失效检查。

### 性能改进

- 复用同一阶段的仓库查询结果，减少 Update 预检和历史加载的重复读取。
- 缩小引用及工作树变化的刷新范围，按脏路径增量更新 Changes。
- 批量读取多选提交详情，移除详情读取不需要的完整 HEAD 历史遍历。
- 复用项目历史首批结果及主仓库元数据，空过滤条件沿用分页读取。
- Push 的终态结果不再读取无须使用的恢复目标。
- 增加可选查询追踪，区分引用观察与操作状态观察的后台开销。

在 Windows、本地独立测试仓库的暖查询样本中，十万提交仓库的多选详情核心耗时由约
1.1 秒降至 0.47–0.59 秒。该数据不等于完整 UI 响应时间，也不代表公网传输速度。
加载一万行的单场景进程组内存峰值约 155 MiB（包含 Git 后代，不含 GPU）；完整大 Diff、
复杂图和长时间重复操作压力验收仍是后续专项。

### 验证与升级

版本号更新前的最终产品代码已通过本地核心测试 998/998、构建、clippy 和相关原生验证。
发布流水线另行运行最终版本的 Linux 核心／桌面、Windows 完整回归和原生打包检查。

下载 `Plico-0.1.0-preview.15-windows-x64.zip`，退出旧版，完整解压到新目录后运行 `Plico.exe`。
保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要混用旧包文件；原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows；同名 `.sha256` 文件用于校验。

仍为 Preview，未代码签名，没有自动更新；尚未完成全部界面的逐像素还原，差异预览保留
5 MiB 限制。源码采用 Apache-2.0，第三方许可证、NOTICE 和来源说明随包提供。
