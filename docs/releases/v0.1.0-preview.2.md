Plico 第二个公开预览版，建议 preview.1 用户升级。

### 修复
- 修复查看/编辑 Tab 缩进文件时缩进显示丢失的问题，保留文件原始内容。
- 调整 F7 差异导航：独立 Diff Tab 到边界后再次按键可切换下一文件，末尾不循环跳回首文件。
- 修复设置、拉取/推送等标题栏按钮的鼠标点击问题。
- 修正从欢迎页打开项目的新窗口位置，压缩“加载更多”区域高度。

### 新增
- Log 右键“将当前分支重置到此处…”，支持 Soft、Mixed、Hard、Keep，默认 Mixed 并记忆确认后的选择。
- 重置前保存编辑内容，执行后刷新 Log、本地变更、文件树和已打开文件。

### 使用与升级
下载 `Plico-0.1.0-preview.2-windows-x64.zip`，退出旧版后将新包完整解压到新目录，运行 `Plico.exe`；原有用户设置保留。不要只替换单个 EXE，辅助程序和许可证文件也应随包保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows。使用同名 `.sha256` 校验下载完整性。

### 已知限制
仍为 Preview，尚未代码签名，没有自动更新。Keep 遇到会覆盖本地更改的情况会报错，暂不提供 Smart Reset 暂存恢复流程；已有未完成 Git 操作或恢复状态时禁止 Reset。Hard 会丢失本地改动，请核对弹窗说明。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
