Plico 第三个公开预览版，建议 preview.2 用户升级。

### 修复
- 仅 CRLF/LF 换行符不同的文件也能显示差异高亮，并提示“仅换行符不同”。
- 嵌入式 Diff 预览加载完整文件上下文，修复只有变更附近片段的问题。
- 修复 Windows 打开 WSL 仓库时，编辑文件保存报“不支持该请求”的问题。
- 修复大量 Git 诊断输出被误报为数据超过 8 MiB 的问题。
- Reset 准备阶段仍可取消；实际写入开始后不再提供取消，避免杀掉 Git 留下半完成状态。
- 修复标题栏主菜单、项目下拉、分支下拉无法左键打开。
- 修复调整窗口边框后，松开鼠标仍会自动选择提交详情文字。
- 修复文件编辑器获得焦点后插入光标不闪烁，以及切换 Tab 后光标消失。

### 使用与升级
下载 `Plico-0.1.0-preview.3-windows-x64.zip`，退出旧版后完整解压到新目录，运行 `Plico.exe`；原有用户设置保留。请同时保留辅助程序与许可证文件，不要仅替换主 EXE。
需要 Windows x64 和 PATH 中可用的 Git for Windows。可使用同名 `.sha256` 校验下载完整性。

### 已知限制
仍为 Preview，未代码签名，没有自动更新。现有文件编辑大小及 Git 数据输出限额保留；此次完整上下文修复不代表所有超大文件或超长单行限制均已解除。WSL 保存的 POSIX executable/ACL 元数据保留尚未验证。Reset 改进不自动恢复此前已被中断的仓库状态，也不提供断电或外部强杀后的事务回滚。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
