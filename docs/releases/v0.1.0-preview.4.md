Plico 第四个公开预览版，建议旧版用户升级。

### 改进与修复
- Diff 双栏支持拖动分隔线，行号靠近中栏；新增／删除在空侧显示细线，并用曲线连接两侧差异。
- 历史与工作区双栏按差异位置同步滚动，修复新 Tab 只显示部分文件、需要反复 F7 才出现后续内容的问题。
- 改进 Diff 高亮、还原操作及界面／编辑器字体设置，并整理相关模块。
- 本地更改刷新减少重复全仓库扫描，合并进行中的重复刷新请求。Windows 访问 WSL 的 Spring 测试样本约从 3.47 秒降到 2.11 秒；实际耗时取决于仓库和磁盘。
- Git 查询取消／超时会清理整个子进程树，避免后台扫描继续占用输出管道、界面长时间等待。
- F7 跨文件提示自动消失；切换 Diff 文件时同步来源文件列表的选择。
- 验证提交完成后 Log 自动刷新，并补充刷新、取消和选择同步的回归测试。

### 下载与升级
下载 `Plico-0.1.0-preview.4-windows-x64.zip`，退出旧版后完整解压到新目录，运行 `Plico.exe`。保留包内辅助程序和许可证文件；原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows。同名 `.sha256` 文件用于校验完整性。

### 已知限制
仍为 Preview，未代码签名，没有自动更新。Windows Git 通过 UNC 访问大型 WSL 仓库仍可能较慢：3 万文件压力样本仍触发 30 秒查询超时，但现在能结束且无残留进程。尚未切换为 WSL 内 Git 执行。滚动手感及所有视觉细节尚未完成完整验收；现有文件大小和 Git 数据输出限制保留。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
