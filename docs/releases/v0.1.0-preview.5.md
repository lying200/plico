Plico 第五个公开预览版。

### 改进与修复
- 修复收起／展开侧栏时源码变更标记滞留旧位置的问题，标记与点击区域使用同一帧的布局坐标。
- 修复 Diff 中栏连接高亮的绘制时序；打开 Diff 默认定位首处差异，F7／Shift+F7 导航保留合适的上下文。
- 源码编辑器显示 Git 行变更标记，支持查看原内容、导航及撤回单块变更。
- 外部文件修改同步到已打开的编辑器和本地 Diff；存在未保存编辑时保留草稿并提示冲突，外部删除不会被自动保存重新创建。
- 自动刷新 Git Log，显示当前分支的传入／传出更新提示。
- 支持编辑提交信息，并调整 Reset 弹窗布局。
- 辅助程序统一改名为 `plico-askpass.exe` 和 `plico-editor.exe`，构建、调用与打包清单同步更新。

### 下载与升级
下载 `Plico-0.1.0-preview.5-windows-x64.zip`，退出旧版后完整解压到新目录，运行 `Plico.exe`。请保留同目录的两个 `plico-` 辅助程序，不要只替换主程序或混用旧包文件。原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows；同名 `.sha256` 文件用于校验。

### 已知限制
仍为 Preview，未代码签名，没有自动更新。Windows Git 通过 UNC 访问大型 WSL 仓库仍可能较慢；尚未切换为 WSL 内 Git 执行。外部文件冲突暂未提供三方合并；UNC 通知丢失时依靠周期补偿刷新。滚动手感和所有视觉细节尚未完整验收。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
