Plico 第六个公开预览版。

### 新增与改进
- 编辑器变更标记支持直接提交单个变更块。
- 并排 Diff 支持勾选多个变更块，以及在块内包含／排除部分行；与 Commit 面板共享选择，支持与整文件混合提交。
- Commit 面板加入变更 Rollback；Stash 整合到 Commit 页签并提供上下文操作。
- 对齐分支和标签的 checkout 操作，分支弹窗提供 Fetch 按钮与执行中的加载状态。
- 项目文件树增加路径相关操作，优化本地变更刷新和文件检查范围。

### 修复
- Diff 两侧滚动在绘制前同步，修复中间连接高亮错位。
- 切换 Log 提交与本地变更时，底部 Diff 预览同步切换来源。
- Log 位于顶部时，刷新出现新提交后保持顶部位置。
- 整理提交反馈与恢复诊断，保留失败后的恢复信息。

### 下载与升级
下载 `Plico-0.1.0-preview.6-windows-x64.zip`，退出旧版后完整解压到新目录，运行 `Plico.exe`。请保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要只替换主程序或混用旧包文件。原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows；同名 `.sha256` 文件用于校验。

### 已知限制
仍为 Preview，未代码签名，没有自动更新。部分行／块选择控件目前仅支持并排 Diff；Unified 模式保留已有选择，但尚无逐块／逐行控件。重命名、整文件新增或删除仍按整文件提交。基线或文件内容改变时，旧的部分选择会失效，需要重新选择。
Windows Git 通过 UNC 访问大型 WSL 仓库仍可能较慢。外部文件冲突暂未提供三方合并。滚动手感和所有视觉细节尚未完整验收。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
