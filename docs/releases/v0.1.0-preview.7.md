Plico 第七个公开预览版，主要改善 Windows 本地仓库的操作响应。

### 改进与修复
- 优化 Windows Git 子进程启动，避免每条命令枚举系统全部线程；保留进程树取消和清理机制。
- 优化 Log 当前 HEAD 历史归属查询，减少大仓库重复分页遍历，并保持流式、有限内存处理。
- 增加有容量上限的提交详情缓存，减少重复选择提交时的等待。
- 减少 Reset 和编辑提交信息／Squash 的重复查询，保留执行前状态复验、冲突检查和取消保护。
- 修复同名本地分支可能被误判为受保护远端分支的问题。
- 为历史、提交详情和本地更改刷新补充加载反馈。

### 下载与升级
下载 `Plico-0.1.0-preview.7-windows-x64.zip`，退出旧版后完整解压到新目录，运行 `Plico.exe`。请保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要只替换主程序或混用旧包文件。原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows；同名 `.sha256` 文件用于校验。

### 已知限制
仍为 Preview，未代码签名，没有自动更新。大仓库和 Windows 经 UNC 访问 WSL 仓库仍可能有等待；本次优化不保证所有操作即时完成。
部分行／块选择控件目前仅支持并排 Diff；Unified 模式保留已有选择，但尚无逐块／逐行控件。重命名、整文件新增或删除仍按整文件提交。基线或文件内容改变时，旧的部分选择会失效，需要重新选择。
外部文件冲突暂未提供三方合并，滚动手感和所有视觉细节尚未完整验收。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
