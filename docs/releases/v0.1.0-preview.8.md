Plico 第八个公开预览版，补齐常用 Git 操作流程，并改善冲突处理与界面一致性。

### 功能与改进
- 新增克隆仓库、远端管理和提交身份设置。
- 支持分支创建与受保护的删除流程、分支合并、撤销提交及操作恢复。
- 内置三方文本合并：左右分别采纳或忽略，支持追加另一侧内容；移除外部合并工具入口。
- 修复手动编辑合并结果后丢失采纳状态的问题；撤销／重做同步恢复文本、块范围和解决状态。
- 修复合并结果已写回、暂存失败后无法重试的问题，继续保护外部文件修改。
- 远端分支和标签检出遇到本地覆盖时，支持智能检出或显式强制检出。
- 修复磁盘删除已打开文件后可能阻塞 Tab 关闭和后续操作的问题。
- F7 跨文件导航保留焦点；调整 Log 右侧展示、底部 Diff 预览、字体缩放、中英文文案及窄面板布局。
- 左侧工具栏支持拖动排序；项目树增加定位当前文件、折叠和复制路径操作。

### 下载与升级
下载 `Plico-0.1.0-preview.8-windows-x64.zip`，退出旧版后完整解压到新目录，运行 `Plico.exe`。请保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要混用旧包文件。原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows；同名 `.sha256` 文件用于校验。

### 验证与已知限制
核心测试 613 项通过，并完成 Windows 原生合并、失败重试、远端智能检出及标签强制检出验证。
桌面测试仍有一项既有 Diff 释放布局测试失败，已在修改前版本复现；其余 65 项通过、1 项原有忽略。未宣称所有视觉与滚动细节完成验收。
内置文本合并目前支持 UTF-8、5 MiB 以内内容；符号链接、子模块及不支持的内容继续通过冲突列表处理。
仍为 Preview，未代码签名，没有自动更新。部分行／块选择控件仅支持并排 Diff；重命名、整文件新增或删除仍按整文件提交。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
