Plico 第九个公开预览版，重点完善 Git 认证与托管账号使用流程。

### 功能与修复
- 支持 GitHub、GitLab 浏览器授权与 Token 登录，在 Clone 窗口浏览账号仓库及头像；支持自建 GitLab 的 Token 和 OAuth 应用配置。
- 新增 GitHub/GitLab 账号设置，支持添加、移除、重新登录及当前项目默认账号；取消设置不会保存账号草稿。
- Git 操作支持匹配账号选择、失效凭据重新登录和手动凭据/helper 回退；修复失效绑定阻止有效账号回退的问题。
- 接入 SSH AskPass，支持密钥口令、密码、PIN、交互提示及主机确认；静默后台检查不会弹出认证窗口。
- 认证失败按账号、目标和凭据版本隔离，避免错误清除其他账号的有效凭据；OAuth 回调跳转到不含授权码的结果页。
- 对齐变更文件树的连续目录折叠、平铺文件名与路径排列，以及提交复选框和 Clone 输入框焦点样式。
- 更新 Windows exe 文件属性版本，与发行包版本保持一致。

### 下载与升级
下载 `Plico-0.1.0-preview.9-windows-x64.zip`，退出旧版，完整解压到新目录并运行 `Plico.exe`。请保留同目录的 `plico-askpass.exe` 和 `plico-editor.exe`，不要混用旧包文件。原有用户设置保留。
需要 Windows x64 和 PATH 中可用的 Git for Windows；同名 `.sha256` 文件用于校验。

### 验证与已知限制
认证改动已通过核心回归与认证表单测试，并在 Windows 原生程序核对账号选择、重新登录、取消、账号草稿及 SSH 提示。流水线会再次执行核心测试和 Windows 构建。
GitHub Enterprise 不在当前范围；Clone 仓库按账号切换并手动分页。真实组织 SSO、硬件 PIN、自建 GitLab OAuth、特殊代理和证书环境尚未完成专项验收；界面未宣称逐像素完全一致。
仍为 Preview，未代码签名，没有自动更新。首次 SSH 主机信任及平台授权仍需用户确认。

源码采用 Apache-2.0；第三方许可证、NOTICE 和来源说明随包提供。
